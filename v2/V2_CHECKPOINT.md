# AI 理性陪跑 V2｜P0 Checkpoint

日期：2026-10-02

## 本版目的
不是重寫百家／539/Bingo 演算法，而是把既有底層升級成能快速開始、資訊有份量、三模式共用會員的產品骨架。

## 已完成

### 百家 AI V2 P0
- LINE 圖片訊息支援：百家模式可直接上傳目前桌面路單截圖。
- 新增 `road_vision.py`：OpenCV 顏色＋格線幾何辨識，不使用付費 Vision API。
- 辨識採保守策略：信心不足時不會自動帶入，更不會捏造路單。
- 支援珠盤路候選與大路候選的幾何重建。
- 截圖辨識成功後直接建立牌路並進入分析，不再要求「完成匯入 → 開始分析」。
- 手動 fallback 支援一次貼上：`牌路 紅藍紅紅藍…`，也支援莊/閒/和與 B/P/T。
- 實戰每局改為一次操作：🔴紅 / 🔵藍 / 🟢和，輸入後立即重算。
- 對子與高低牌不再是每局強制流程；原資料欄位／副模型保留。
- V15 原演算法保留，新增 V2 多訊號證據層：近期比例、序列匹配、尾段動能、交錯結構、路況穩定。
- 原本容易被看成「勝率」的百分比不再當前台機率宣稱，改顯示「訊號指數 0-100」。
- 即時分析盤顯示：綜合判讀、訊號指數、風險、路況、五項訊號共識、支持/反向訊號、即時數據、最近牌路。

### 539 AI V2 顯示層
- 保留現有 30/60/120/240 期、頻率、遺漏、區段、母盤、2/3/4星模型。
- 不改現有選號核心，新增每個母盤號碼的診斷資料：模型分數、30期頻率、60期頻率、遺漏期數、區段、標籤。
- 今日輸出升級為：母盤10碼、核心5碼、AI熱度Top3、2/3/4星、逐號依據、區段、模型狀態、最近自動驗證。
- Format 失敗時不再回傳一組固定假「今日號碼」，改成明確資料異常訊息。

### Bingo AI V2 基線
- Bingo 正式保留為第三個模式。
- 已停用「抓不到真實資料就生成模擬開獎」的 fallback。
- `fallback_bingo_results()` 保留相容介面但只回傳空資料。
- 真實資料抓不到時不產生模型號碼，直接顯示資料暫時不可用。
- 單一會員權限涵蓋百家＋539＋Bingo。

### Gateway / 會員
- 主選單改為：百家 AI / 539 AI / Bingo AI / 分析紀錄 / 使用教學 / 會員中心。
- `active_mode` 支援 `baccarat / 539 / bingo`。
- 新增 `interest_bingo`，用於興趣與推播分流，不作為權限限制。
- 正式會員與免費體驗皆為三模式共用。
- Gateway 支援 LINE image message；只有百家模式會觸發路單辨識。

## 測試結果
- Python 靜態編譯：通過。
- `road_vision.py` synthetic 珠盤路測試：24 個符號，22 把莊閒主路，辨識信心 89%，順序完全還原。
- 百家文字快速匯入、V2 分析盤、單擊回填主結果：邏輯測試通過。
- 539 診斷欄位 synthetic 歷史資料測試：10碼母盤診斷完整產生。
- Bingo 空資料測試：不再產生模擬號碼。

2. 截圖辨識成功後目前會顯示預覽，但尚未加入「一鍵確認 / 一鍵修正單格」的完整校正 UI。
